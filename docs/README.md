# PowerTrailBuddy documentation

Organised by [Diátaxis](https://diataxis.fr): four kinds of document, one per
kind of need.

| You want to… | Read |
| --- | --- |
| Use the app for the first time | [Getting started](tutorials/getting-started.md) — tutorial |
| Get a Pocket Query into the app, install it, walk a trail | [User guide](how-to/user-guide.md) — how-to |
| Run a check, add a test, deploy, set up a fork | [Developer guide](how-to/developer-guide.md) — how-to |
| Know what exists: modules, contracts, storage, service worker, CI | [Architecture](reference/architecture.md) — reference |
| Know what a trail setting or threshold is set to | [Configuration](reference/configuration.md) — reference |
| Know which risks the tests cover, and where | [Risk model](reference/risk-model.md) — reference |
| Know why something is built the way it is | [Design decisions](explanation/design-decisions.md) — explanation |

Local setup and the pre-PR checklist live in [CONTRIBUTING.md](../CONTRIBUTING.md);
the testing methodology in [TEST_STRATEGY.md](../TEST_STRATEGY.md). The guides
here link to both rather than repeat them.
